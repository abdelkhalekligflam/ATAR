# Typography

Self-hosted WOFF2 fonts, converted from Google Fonts sources. Original SIL Open Font Licenses are included.

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Instrument Serif (regular and italic): https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Noto Sans Arabic: https://github.com/google/fonts/tree/main/ofl/notosansarabic

Loaded via next/font/local. Arabic is not preloaded on Latin pages.
